# Contributing to Road to ML

Thank you for using Road to ML. This curriculum is **maintainer-curated**.

## Public contributions

**At the moment we do not accept any public contributions.**

That includes:

- Pull requests
- Patches or suggested diffs
- Community edits to lessons, code, or docs
- Guest chapters or co-authored modules

All changes to the repository are made by the maintainer only. This keeps the syllabus consistent and lets updates ship on a single timeline.

If you open a pull request, it will be closed with a link to this file. You do not need to delete your fork.

## What you can do

### Report a problem (optional)

You may open a [GitHub Issue](https://github.com/road-to-machine-learning-and-ai/roadmap/issues) only to **report** something broken. That is not a contribution request, and there is no promise of a public reply timeline.

Useful reports:

- Broken or outdated links
- Factual errors in a lesson
- Typos that change meaning

Please include the **file path or module name**, what you expected, and what you saw.

### Learn and fork

- Read and star the repo
- Fork for your own study notes (MIT License)
- Cite the repository if you reuse material in courses or posts

Forks do not receive automatic updates from this repo unless you sync while following upstream changes yourself. A personal fork is not a contribution channel.

## Style reference (for maintainers)

When editing lessons, follow [WRITING-STYLE.md](WRITING-STYLE.md) for tone, numbering (Module vs Stage), and punctuation.

## Questions

Open an issue with the **question** label if you need clarification about the curriculum.

Thank you for learning with Road to ML.
